# Dhaka Tesla Pool

Share a seat. Split the fare. Survive Dhaka traffic.

A ride-pooling MVP: passengers (Nusrat, Rafiq, Shirin) request rides, and when their routes overlap they share a three-seat Tesla (Jashim's _Bullet_) and each pay their own fare.

> 🚧 Work in progress: setup, architecture, and run instructions will be documented here as the project is built.
